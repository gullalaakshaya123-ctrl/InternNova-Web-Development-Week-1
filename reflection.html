My Web Development Internship Reflection

During the first week of my Web Development Internship at InternNova, I learned the fundamentals of HTML5 and how to create basic web pages. This internship helped me understand the structure of an HTML document, including the DOCTYPE, html, head, and body elements.

I practiced using headings, paragraphs, text formatting, links, images, lists, and tables. I also learned how to create a student registration form using different input elements. Understanding semantic HTML elements such as header, nav, main, section, article, and footer was another important part of my learning.

As part of the mini project, I created a personal resume website using HTML5. This practical work improved my understanding of webpage structure and helped me apply the concepts I learned. Initially, I faced some difficulties with writing and organizing HTML code, but practicing each task helped me improve.

Overall, this first week was a valuable learning experience. I gained confidence in writing HTML code and look forward to learning more about web development in the coming weeks.
